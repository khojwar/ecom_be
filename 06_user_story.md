A user story is a short, simple description of a feature told from the perspective of the person who desires the new capability — usually a user or customer of the system. It’s commonly used in Agile development to capture requirements.

## Basic Format (INVEST Model)
    As a [type of user],
    I want [some goal],
    so that [some reason].

## Example User Stories
### For a Task Manager App
* As a registered user,
 
    I want to create tasks with deadlines,
    so that I can keep track of my work.

* As a team member,
    
    I want to assign tasks to others,
    so that everyone knows their responsibilities.

### For a Job Portal
* As a job seeker,
    
    I want to search jobs by location and category,
    so that I can find relevant opportunities.

* As a company,
    
    I want to view applicants for a job post,
    so that I can evaluate and shortlist candidates.
